# M3: Controls — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** EchoLine can be controlled without hunting for the overlay: a tray icon, a hover bar on the captions, global hotkeys, click-through, auto-hide, microphone captioning, start with Windows, and the always-on-top switch back.

**Architecture:** App-level actions (`set_visible`, `set_paused`, `set_source`, `set_click_through`) live on `EchoLineApp` and are triggered from four places: the QML hover bar (via `Controller` slots), the tray menu (`TrayIcon`, Qt Widgets), global hotkeys (`HotkeyManager`, Win32 `RegisterHotKey` + a native event filter), and the settings window. New settings persist in the existing `SettingsStore`. A shared WASAPI source base serves both system audio (loopback) and the microphone.

**Tech Stack:** Python 3.11, PySide6 6.11.2 (QtQuick, QtWidgets for `QSystemTrayIcon`), PyAudioWPatch, pycaw, `ctypes` (user32), `winreg`, pytest.

**Spec:** `docs/superpowers/specs/2026-10-03-echoline-v1-design.md` (QML UI → HoverBar, tray; Supporting services → global hotkeys, single instance; Customization → Position & behavior; Milestone M3).

**Decisions made with the user (2026-10-03):** default hotkeys Ctrl+Alt+C (show/hide), Ctrl+Alt+P (pause), Ctrl+Alt+T (click-through), changeable in settings; microphone captioning is added and the hover bar's source button toggles System audio / Microphone; auto-hide fades captions after 5 s of silence and is off by default; a "Start with Windows" switch adds a per-user Run entry.

## Global Constraints

- Windows 10+, Python >= 3.10, `.venv/Scripts/python`; `moonshine.dll` still loads before Qt.
- The app now uses `QApplication` (Qt Widgets) because `QSystemTrayIcon` needs it; tests already use `QApplication`.
- The overlay's ✕ hides the captions (restore from the tray, the hotkey or by launching again); Quit lives in the tray menu and the right-click menu.
- Hotkey strings use Qt's portable text form, e.g. `"Ctrl+Alt+C"`; an empty string disables a hotkey.
- No new third-party dependencies.
- Tests need no audio device, model, real registry or real hotkeys: Win32 and `winreg` are injected and faked.
- Commits: imperative summary plus a "why" body; never mention AI tools or co-authors; one logical change per commit; full suite green before each commit.

## Review Focus

1. **Click-through turned on, then the user cannot find a way back**: the tray menu and the Ctrl+Alt+T hotkey must always turn it off, and the tray item shows its state — pinned in Task 7 (`test_click_through_can_always_be_turned_off_from_the_tray`).
2. **A hotkey already taken by another app**: registration fails; the app must keep running, tell the user which hotkey is unavailable, and keep the others working — pinned in Task 5 (`test_taken_hotkey_is_reported_and_others_still_register`).
3. **No microphone (or microphone permission denied in Windows privacy settings)**: switching to Microphone must show "No microphone" and keep retrying, not crash — pinned in Task 3 (`test_missing_microphone_reports_no_device`).
4. **Pausing mid-sentence, then resuming**: the paused partial must be finalized and new speech must start a new line, with nothing captured while paused — pinned in Task 4 (`test_pause_finalizes_and_ignores_audio_until_resumed`).
5. **Auto-hide while a status needs attention**: captions may fade, but "No audio device", "Paused" or errors must stay visible — pinned in Task 9 (`test_auto_hide_keeps_status_visible`).

### Task 5: Global hotkeys

**Files:**
- Create: `echoline/hotkeys.py`
- Modify: `echoline/app.py`
- Test: `tests/test_hotkeys.py`

**Interfaces:**
- Produces:
  - `parse_hotkey(text: str) -> tuple[int, int] | None` — `"Ctrl+Alt+C"` → `(MOD_CONTROL | MOD_ALT | MOD_NOREPEAT, ord("C"))`; F1–F12 → `0x70 + n - 1`; digits → `ord`; `""` or invalid → `None`. Modifier bits: Alt 0x1, Ctrl 0x2, Shift 0x4, Win 0x8, NoRepeat 0x4000.
  - `HotkeyManager(hwnd: int, user32=None)` (also a `QAbstractNativeEventFilter`): `register(name, text, callback) -> bool`, `unregister_all()`, `failed` (list of names that could not be registered). `nativeEventFilter` consumes `WM_HOTKEY` (0x0312) for its ids and calls the callback (returns `(True, 0)`); everything else returns `(False, 0)`.
  - `EchoLineApp` creates a hidden `QWindow` for the hotkey HWND, installs the manager as a native event filter on `QCoreApplication`, registers the three hotkeys from settings, re-registers when they change, and unregisters on shutdown. Unavailable hotkeys show the status `"hotkey-taken"` for 6 s with text "Hotkey <keys> is used by another app".

```python
import ctypes
from ctypes import wintypes

from PySide6.QtCore import QAbstractNativeEventFilter

MODIFIERS = {"Alt": 0x1, "Ctrl": 0x2, "Shift": 0x4, "Win": 0x8}
MOD_NOREPEAT = 0x4000
WM_HOTKEY = 0x0312


def parse_hotkey(text):
    """'Ctrl+Alt+C' -> (modifier bits, virtual key), or None if empty/invalid."""
    parts = text.split("+") if text else []
    if len(parts) < 2:
        return None
    *mods, key = parts
    if any(m not in MODIFIERS for m in mods):
        return None
    if len(key) == 1 and (key.isdigit() or "A" <= key <= "Z"):
        vk = ord(key)
    elif key.startswith("F") and key[1:].isdigit() and 1 <= int(key[1:]) <= 12:
        vk = 0x70 + int(key[1:]) - 1
    else:
        return None
    bits = MOD_NOREPEAT
    for m in mods:
        bits |= MODIFIERS[m]
    return bits, vk


class HotkeyManager(QAbstractNativeEventFilter):
    """System-wide hotkeys via RegisterHotKey on a hidden window."""

    def __init__(self, hwnd, user32=None):
        super().__init__()
        self._hwnd = hwnd
        self._user32 = user32 or ctypes.windll.user32
        self._callbacks = {}      # id -> callback
        self._next_id = 1
        self.failed = []

    def register(self, name, text, callback):
        parsed = parse_hotkey(text)
        if parsed is None:
            return False
        hotkey_id = self._next_id
        self._next_id += 1
        if not self._user32.RegisterHotKey(self._hwnd, hotkey_id, *parsed):
            self.failed.append(name)
            return False
        self._callbacks[hotkey_id] = callback
        return True

    def unregister_all(self):
        for hotkey_id in list(self._callbacks):
            self._user32.UnregisterHotKey(self._hwnd, hotkey_id)
        self._callbacks.clear()
        self.failed = []

    def nativeEventFilter(self, event_type, message):
        msg = wintypes.MSG.from_address(int(message))
        if msg.message == WM_HOTKEY and msg.wParam in self._callbacks:
            self._callbacks[msg.wParam]()
            return True, 0           # consume: Windows delivers it through two hooks
        return False, 0
```

```python
from PySide6.QtCore import QRectF, Qt
from PySide6.QtGui import QColor, QFont, QIcon, QPainter, QPixmap


def app_icon():
    """A rounded dark badge with 'CC', drawn so no image assets are needed."""
    icon = QIcon()
    for size in (16, 24, 32, 48, 256):
        pixmap = QPixmap(size, size)
        pixmap.fill(Qt.transparent)
        painter = QPainter(pixmap)
        painter.setRenderHint(QPainter.Antialiasing)
        painter.setBrush(QColor("#1f1f1f"))
        painter.setPen(Qt.NoPen)
        painter.drawRoundedRect(QRectF(0, 0, size, size), size * 0.22, size * 0.22)
        font = QFont("Segoe UI", 1, QFont.Bold)
        font.setPixelSize(int(size * 0.5))
        painter.setFont(font)
        painter.setPen(QColor("#ffffff"))
        painter.drawText(QRectF(0, 0, size, size), Qt.AlignCenter, "CC")
        painter.end()
        icon.addPixmap(pixmap)
    return icon
```

`echoline/autostart.py`:
```python
import sys
from pathlib import Path

RUN_KEY = r"Software\Microsoft\Windows\CurrentVersion\Run"
VALUE = "EchoLine"


def launch_command():
    if getattr(sys, "frozen", False):
        return f'"{sys.executable}"'
    pythonw = Path(sys.executable).with_name("pythonw.exe")
    return f'"{pythonw}" -m echoline'


def _registry(registry):
    if registry is None:
        import winreg as registry
    return registry


def set_start_with_windows(enabled, registry=None):
    reg = _registry(registry)
    with reg.OpenKey(reg.HKEY_CURRENT_USER, RUN_KEY, 0, reg.KEY_SET_VALUE) as key:
        if enabled:
            reg.SetValueEx(key, VALUE, 0, reg.REG_SZ, launch_command())
        else:
            try:
                reg.DeleteValue(key, VALUE)
            except FileNotFoundError:
                pass


def is_start_with_windows(registry=None):
    reg = _registry(registry)
    try:
        with reg.OpenKey(reg.HKEY_CURRENT_USER, RUN_KEY, 0, reg.KEY_READ) as key:
            reg.QueryValueEx(key, VALUE)
            return True
    except FileNotFoundError:
        return False
```

Update `launch_command` and its test accordingly (`assert "-m echoline" in launch_command()`).

```python
    def _apply_autostart(self):
        wanted = self.settings_store.settings.start_with_windows
        if wanted != self._autostart_applied:
            self._autostart_applied = wanted
            try:
                set_start_with_windows(wanted)
            except OSError:
                self.status.set_notice("Could not change start with Windows")
```

```qml
    component HotkeyButton: Button {
        property string key
        property bool recording: false
        text: recording ? "Press keys…" : (win.s[key] || "None")
        onClicked: { recording = true; forceActiveFocus() }
        Keys.onPressed: (event) => {
            if (!recording) return
            event.accepted = true
            if (event.key === Qt.Key_Escape) { recording = false; return }
            if (event.key === Qt.Key_Backspace) { settingsStore.setValue(key, ""); recording = false; return }
            const names = []
            if (event.modifiers & Qt.ControlModifier) names.push("Ctrl")
            if (event.modifiers & Qt.AltModifier) names.push("Alt")
            if (event.modifiers & Qt.ShiftModifier) names.push("Shift")
            if (event.modifiers & Qt.MetaModifier) names.push("Win")
            let k = ""
            if (event.key >= Qt.Key_A && event.key <= Qt.Key_Z) k = String.fromCharCode(event.key)
            else if (event.key >= Qt.Key_0 && event.key <= Qt.Key_9) k = String.fromCharCode(event.key)
            else if (event.key >= Qt.Key_F1 && event.key <= Qt.Key_F12) k = "F" + (event.key - Qt.Key_F1 + 1)
            if (k === "" || names.length === 0) return        // keep waiting for a full combination
            settingsStore.setValue(key, names.concat([k]).join("+"))
            recording = false
        }
    }
```
